## `04 · como eu trabalho`

- **Migrations idempotentes** — ledger por migration, deploy simultâneo em múltiplas produções a partir de um repo só.
- **CI/CD de verdade** — GitHub Actions + Docker + VPS, deploys repetíveis.
- **Refactor incremental** — Vue 3 convivendo com legado jQuery, sem big-bang rewrite.
- **Zero deploy na sexta sem rollback.**
